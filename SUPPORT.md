# Support

This project is a Windows prototype, not a managed service or emergency interpretation tool.

## Getting help

1. Run `./.venv/Scripts/python.exe ./scripts/doctor.py` from PowerShell.
2. Check the [README](README.md), [Call Bridge setup](docs/call-bridge-operator-setup.md), and
   existing GitHub issues in this repository.
3. Open a support question with Windows version, Python version, the command run, and a redacted
   error message.

Do not attach recordings, transcripts, API tokens, Windows endpoint IDs, or personally identifying
call data. For Call Bridge questions, state whether the issue occurs before or after the explicit
hardware/operator acceptance checks. Security concerns belong in [SECURITY.md](SECURITY.md).
