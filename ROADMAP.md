# Roadmap

The order below is intent, not a delivery promise.

## Current: evidence-led prototype

- Maintain offline, utterance-based German/Mandarin conversation translation.
- Complete automated regression coverage and reproducible local setup/build checks.
- Keep the Call Bridge disabled by default and fail closed on endpoint ambiguity or loss.

## Next: Call Bridge acceptance

- Run the packaged dual-lane check on a supported Windows system.
- Complete the two-virtual-cable isolation and disconnect/reconnect checklist.
- Validate a real two-party call only with participant consent and without publishing call content.

## Later, only after the preceding gates

- Investigate streaming partial results, cancellable speech, and process loopback.
- Evaluate echo control, accessibility improvements, and more hardware profiles.

No date, latency, compatibility, or language-quality commitment is implied by this roadmap.
